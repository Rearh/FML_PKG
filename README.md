# fml_pkg
Минималистичный source-based пакетный менеджер для Linux From Scratch.

## Установка
sudo ./scripts/install_self.sh

## Команды
* sudo fml_pkg sync — обновить индекс пакетов
* sudo fml_pkg install <имя> — собрать и установить пакет
* sudo fml_pkg update [имя] — обновить пакеты
* sudo fml_pkg remove <имя> — удалить пакет
